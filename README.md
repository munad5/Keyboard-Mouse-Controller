# Keyboard Mouse Controller

A Python tool that lets you control the mouse using keyboard shortcuts. Move the cursor, scroll, and simulate mouse clicks without touching the mouse.

## Controls

- `Arrow keys` — move cursor
- `Shift + Arrow keys` — move cursor faster
- `Alt + Up/Down` — scroll slowly
- `Space + Up/Down` — scroll fast
- `Ctrl + Enter` — left click (hold to drag)
- `Shift + Enter` — right click (hold to drag)

## Activation

- `A + M + K` — start
- `S + M + K` — stop

## Requirements

pip install pyautogui keyboard

## Notes

Run as administrator if keypresses are not detected correctly.
